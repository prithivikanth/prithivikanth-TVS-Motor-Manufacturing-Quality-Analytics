# TVS Motor Manufacturing Quality, Defect and Production Analytics

**Project by:** Prithivi Kanth S

This repository contains a manufacturing analytics portfolio project demonstrating how production and quality data can be explored using SQL and Power BI.

> **Important:** This project uses synthetic practice data. It is not real TVS Motor Company data and does not describe the company's actual operational performance.

## Project Documentation

Start with the detailed project documentation:

- [Read the full project documentation](TVs_Poject/README_TVS_Project.md)
- [Open the project folder](TVs_Poject/)

## Project Goals

- Analyse production output and quality defects.
- Compare quality measures across plants, machines, products and shifts.
- Explore defect categories, recorded root causes, downtime and rework.
- Use SQL to validate and analyse data.
- Present key metrics and comparisons in Power BI.

## Tools

- **Excel** — data cleaning and validation
- **MySQL** — data preparation and analytical queries
- **Power BI Desktop** — data modelling, measures and dashboards
- **GitHub** — source control and project documentation

## Repository Contents

The project files are organised under the `TVs_Poject/` folder. Browse that folder to find the available documentation, datasets, SQL scripts, Power BI files and screenshots. The exact files available may change as the project is updated.

## How to Explore the Project

1. Open the [project folder](TVs_Poject/).
2. Read [README_TVS_Project.md](TVs_Poject/README_TVS_Project.md) for the project overview, methodology, analysis workflow, limitations and reproduction guidance.
3. Review the available SQL scripts and datasets.
4. Open any available Power BI report in Power BI Desktop.
5. Treat the results as practice analysis based on synthetic data, not as verified company metrics.

## Limitations

- The dataset is synthetic and is not official TVS Motor Company data.
- Results depend on the data and analysis rules used in this project.
- Observed patterns do not prove cause and effect.
